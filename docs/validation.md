| 驗證 | 結果 | 涵蓋內容 |
| --- | --- | --- |
| `npm run build` | 通過 | TypeScript 檢查與 Vite 正式建置；CSS 隨建置輸出 |
| `npm test` | 22／22 通過 | 歷史快照、封存、分類移轉、匯入、帳號隔離、衝突、快取損壞與備份失敗 |

| `npm run test:purchase` | 通過 | 390、1440px；採購狀態篩選、勾選、持久化、檔期隔離、取消訂單排除與 Excel |
| `npm run test:upgrade` | 通過 | 390、1440px；草稿切換／重整、商品修改保留舊價、分類移轉、封存與恢復、各檔期成本、拒絕無效匯入、歷史檔期修復 |
| `npm run test:accounts` | 通過 | Auth／Firestore Emulators；A／B／訪客與草稿隔離、登入無寫入、跨裝置勾選與成本、過期編輯視窗、舊客戶端／跨帳號／不完整資料拒絕 |

正式資料另以私人備份進行唯讀相容比對，確認所有歷史檔期、商品、訂單、分類與選項陣列的內容不變。帳號內容、備份與真實截圖不包含在這個公開專案中。公開截圖均由明確載入的訪客示範資料產生。

瀏覽器與模擬器測試使用虛構資料，沒有在正式帳號建立測試訂單。跨裝置與寫入權限的整合證據來自本機 Firebase 模擬器；正式 Google 登入視窗與實際使用者裝置的登入後操作未以自動化測試覆蓋。
