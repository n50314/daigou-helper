# 一般代購分類與品項對照

這份表格對照介面用詞與新增分類。歷史訂單與既有選項內容保持原樣，顯示名稱的調整不會重新命名實際客戶已訂購的商品或款式。

| 原本概念／用詞 | 更新後 | 使用方式 |
| --- | --- | --- |
| 偶像團體／團體設定 | 品牌、系列的選項群組 | 例如品牌 A 下的保養、彩妝系列；不需要固定選項時可不設定 |
| 二期、三期等分組 | 系列／型號／款式分組 | 新群組可建立日用品、配件、容量版本等分組；歷史分組保留 |
| 成員選項 | 款式／型號選項 | 用於商品固定版本、型號或系列 |
| 成員商品（舊分類 ID `member`） | 指定款式商品 | 沿用舊 ID 與選項，顯示通用名稱 |
| 生寫真（舊分類 ID `photo`） | 紙品收藏 | 可涵蓋卡片、明信片、紙品；既有訂單名稱與規格保留 |
| 隨機／不挑款 | 不指定款式 | 新訂單採用一般購物用詞，歷史文字保持原樣 |
| 固定尺寸選單 | 尺寸／容量自由輸入 | 可填 M、200ml、128GB、500g、版本等，仍提供常見尺寸建議 |
| 只有特定商品可填規格 | 所有商品皆可選填規格 | 分類設定可要求規格必填或啟用固定選項群組 |
| 全域成本匯率 | 各檔期成本匯率 | 舊檔期尚未設定時沿用舊全域匯率，不會自動重算訂單成交價 |
| 預估淨利潤 | 預估商品毛利 | 明確指出尚未扣除運費與其他費用 |

## 新增一般代購分類

| 分類 | 分類 ID | 品項範例 | 規格範例 |
| --- | --- | --- | --- |
| 服飾配件 | `apparel` | 純棉短袖上衣、肩背包 | 米白／M、黑色／小款 |
| 美妝保養 | `beauty` | 保濕乳液、護唇膏 | 200ml、無香料版 |
| 食品零食 | `food` | 奶油餅乾禮盒、茶葉 | 12 入、500g、紅茶 |
| 生活用品 | `household` | 保溫隨行杯、桌面收納盒 | 500ml、透明／大款 |
| 3C配件 | `electronics` | USB-C 充電線、耳機 | 1m、USB-C、黑色 |
| 文具紙品 | `stationery` | 方格筆記本、明信片 | A5、方格、款式 A |
| 一般商品 | `normal` | 禮盒、其他尚未分類商品 | 自由填寫或留白 |

新工作區直接使用一般分類。既有帳號的自訂分類不會被覆蓋，可至「分類與選項設定」點選「加入一般代購分類」，只補上尚未存在的分類。刪除使用中的分類時，介面會要求選擇商品的移轉目標，並一次更新分類與商品；歷史訂單不參與移轉。

示範品項只會在訪客點選「載入示範資料」時建立，不會自動加入已綁定帳號。
